技術規格

本網站以三種技術構成，並於桌面與行動裝置皆可正常使用。

HTML

語義化標籤結構：header、nav、main、section、article、figure、footer。 全站七個頁面各自獨立，連結皆為相對路徑。

CSS

以變數集中管理配色與間距，採 mobile-first 響應式設計， 於 768px 與 1024px 兩個斷點調整排版。

JavaScript

技能篩選、作品燈箱、導覽高亮、3D 輪盤與Canvas 背景動畫， 全部程式碼置於單一外部檔案。

互動元件

技能分類篩選器、作品集燈箱、輪盤拖曳與鍵盤操作， 以及卡片點擊閃光回饋。

響應式

於 375px、768px、1440px 三種寬度下驗證無橫向捲動， 導覽列於窄螢幕改為hamburger 展開。

效能

Canvas 動畫限幀 30fps 並於分頁隱藏時暫停； 動畫元素於結束後自 DOM 移除，不累積記憶體。
